## 1. 製品概要

### コンセプト
**LowCut Police**は、楽曲の低域（サブベース、キックの不要な被り、マイクの吹かれノイズ等）を徹底的に管理するために開発された高精度イコライザーです。1Hzから表示できる超低域特化型アナライザーと、急峻なスロープを持つローカット/ハイカット、外科手術的なノッチが可能な4バンドのベルEQを組み合わせ、「見えない低域」を見える化して正確に処理します。

### ミニマムフェーズ設計とゼロレイテンシについて
本プラグインの全フィルター（ローカット / ハイカット / ベル）は**ミニマムフェーズ（最小位相）IIR設計**です。

*   **レイテンシは0サンプル**です。DAWの遅延補正は不要で、レコーディング時のインサートやライブ演奏中の使用にも対応します。
*   リニアフェーズEQで問題になる**プリエコー（音の前に滲む逆残響）が原理的に発生しません**。キックやアタックの立ち上がりが濁りません。
*   カットフィルターにはButterworth特性をベースに、初段セクションのQを抑えた**ハイブリッドQ配置**を採用し、急峻なスロープ設定時のポストリンギング（カットオフ付近の尾を引く響き）を低減しています。
*   パラメータ変更は内部で常時スムージングされ、スロープ切替時は新旧フィルターを約10msでクロスフェードします。**オートメーションで激しく動かしてもジッパーノイズやクリックが発生しません。**

### 「設定値どおりに動く」設計思想
本プラグインは、バンド間の相互作用を内部で勝手に補正することはありません。設定した周波数・ゲイン・Qがそのままフィルター係数に反映され、表示カーブと実際の処理は常に完全に一致します（実測誤差 0.01dB 未満）。複数バンドを近接させたときにカーブが足し合わさる挙動は、伝統的なアナログEQ/プロ用EQと同じです。

## 2. 高解像度アナライザー

一般的なEQプラグインのアナライザーはFFT方式（例: 4096ポイント）で、低域の分解能はビン幅（44.1kHz時で約10.8Hz）に制限されます。20Hz以下はわずか2〜3ポイントしか情報がなく、超低域の観察にはほぼ使えません。

LowCut Policeのアナライザーは**FFTを使わない800バンドのアナログ型フィルターバンク方式**です。

*   **1Hz〜60Hzを0.2Hz刻み**（296バンド）、60〜200Hzを1Hz刻み、200Hz〜25kHzを対数等間隔で常時解析。
*   デシメーション（間引き）の前段に8次Butterworthアンチエイリアスフィルタを備え、中高域の成分が超低域に偽スペクトルとして混入しません（折り返し抑制 -110dB以上）。
*   表示レベルは**0dBFSサイン波 = 0dB表示**にキャリブレーション済み（全帯域 ±0.25dB以内）。
*   バンドごとに最適化された応答時定数を持ち、低域はゆっくり正確に、高域は素早く追従します。
*   マルチレート処理により、この規模のフィルターバンクとしては極めて軽量（1コアの数%程度）。

> **豆知識**: 1Hz帯の表示が安定するまで1〜2秒かかりますが、これは不確定性原理による物理限界であり、どの方式のアナライザーでも回避できません。むしろFFT方式では1Hzの分解そのものが不可能です。

## 3. 各セクションとパラメータ解説

下部のバンド選択ボタン（LC / HC / B1〜B4）で操作対象を選ぶと、ノブがそのバンドに接続されます。各バンドの「ON」ボタンで有効/無効を切り替えます。

### ローカット（ハイパス）セクション [LC]
不要な低音をカットするためのメインフィルターです。
*   **Frequency (Hz)**: カットオフ周波数（調整範囲: **1 Hz 〜 500 Hz**、対数スケール、デフォルト 80 Hz）。
*   **Slope (dB/oct)**: フィルターの急峻さ。**12 / 24 / 36 / 48 / 60 / 72 / 84 / 96 dB/oct** の8段階。
*   **Enable (ON/OFF)**: ローカット全体の有効/バイパス。

### ハイカット（ローパス）セクション [HC]
高域側を整理するためのフィルターです。
*   **Frequency (Hz)**: カットオフ周波数（調整範囲: **1 Hz 〜 25,000 Hz**、デフォルト 20 kHz）。
*   **Slope (dB/oct)**: 12 〜 96 dB/oct の8段階。
*   **Enable (ON/OFF)**: ハイカットの有効/バイパス。

### ベルEQセクション（1〜4バンド）[B1〜B4]
特定の周波数を狙ってピンポイントでカット/ブーストするパラメトリックEQです。ナイキスト周波数付近でもカーブが潰れない**Orfanidis型（アナログ整合）設計**を採用しています。
*   **Frequency (Hz)**: ターゲット周波数（調整範囲: **10 Hz 〜 25,000 Hz**）。
*   **Gain (dB)**: 増減量（調整範囲: **-12 dB 〜 +12 dB**）。
*   **Q**: 帯域幅（調整範囲: **0.3 〜 120.0**）。Q=120では極めて鋭いノッチが可能です。EQカーブ表示はスーパーサンプリング描画のため、どんなに鋭いピーク/ノッチでも、どのズーム倍率でも先端まで正確に描画されます。
*   **Enable (ON/OFF)**: バンドごとの有効/バイパス。ON/OFF時もクリックノイズは発生しません（ゲインが滑らかに0dBへ遷移します）。

### グローバルコントロール / モニター系
*   **Bypass**: プラグイン全体の処理をバイパスします。
*   **Diff (Listen Diff)**: 「差分聴取」モード（後述）。
*   **Hold**: アナライザーのピークホールド表示を有効にします。
*   **Color**: 10種類のカラーパレットを切り替えます。
*   **Analyze (表示モード切替)**: クリックするたびにディスプレイが切り替わります。
    *   `Normal`: EQ応答カーブ ＋ リアルタイムアナライザー表示。
    *   `Waveform`: 音声波形表示（Dry / Wet）。
    *   `Phase`: 位相特性表示。

## 4. 高度なモニタリング機能

### Listen Diff (差分聴取)
「Diff」ボタンをONにすると **Dry音 − Wet音**、つまり**「イコライザーによって削り取られた音成分そのもの」**を出力します。
*   **効果的な使い方**: ローカットを強くかけた際、キックの芯やベースの重要な成分が一緒に削られていないかを耳で確認できます。Diffから「不要な風切音や低域ノイズ」だけが聴こえていれば、正しいイコライジングができている証拠です。本プラグインはゼロレイテンシのため、差分は常にサンプル単位で正確です。

### Solo-Sweep (ソロスイープ)
EQポイントを **`Shift` キーを押しながらクリックまたはドラッグ**している間、そのポイントを中心とした鋭いバンドパスフィルターで試聴できます。
*   **効果的な使い方**: ポイントを左右にスイープして、耳障りな共鳴周波数や濁った音を探り当てます。離すと瞬時に元の音に戻るため、素早く問題箇所を特定してノッチカットに移れます。

### Peak Hold (ピークホールド)
「Hold」ボタンをONにすると、各帯域の最大レベルが細線で保持表示されます。曲全体を再生しながら、瞬間的にしか現れない低域のピークやレゾナンスを捕捉するのに便利です。OFFにするとリセットされます。

## 5. 操作ショートカット / ズーム操作一覧

### EQポイントの操作

| 操作方法 | アクション |
| :--- | :--- |
| **ドラッグ (ポイント上)** | 周波数を変更します（ベルは縦方向でゲインも同時に変更）。LC/HC ポイントは実際のカーブ上（カットオフの約 -3dB 地点）に表示されます。ドラッグ中は周波数と音名がツールチップにリアルタイム表示されます。 |
| **マウスホイール (ポイント上)** | ベルの場合は **Q値** を、LC/HC の場合は **Slope** を直接変更します。 |
| **ダブルクリック (ポイント上)** | そのバンドの有効/無効（On/Off）を瞬時に切り替えます。**Off にしたポイントも淡色（ゴースト）で表示され続ける**ので、もう一度ダブルクリックすれば On に戻せます。 |
| **`Shift` + クリック/ドラッグ** | ソロスイープ（前述）。 |

### 表示のズーム / ナビゲーション

| 操作方法 | アクション |
| :--- | :--- |
| **H+ / H− ボタン** | 周波数軸（横）のズームイン/アウト。 |
| **V+ / V− ボタン** | ゲイン軸（縦）のズームイン/アウト（±3 dB 〜 ±48 dB）。 |
| **`Ctrl` + マウスホイール** | **カーソル位置を中心に**周波数軸をズームします（拡大・縮小）。超低域の観察に最適です。 |
| **左右ドラッグ (空きスペース)** | EQ カーブ（表示範囲）を**左右に移動**します。上下方向の操作はありません。 |
| **マウスホイール (空きスペース)** | EQ カーブ（表示範囲）を**左右に移動**します。拡大時・通常時のどちらでも追従します。 |
| **ダブルクリック (空きスペース)** | ズームと表示範囲を初期状態にリセット。 |
| **カーソルホバー / ドラッグ中** | カーソル位置（ドラッグ時は操作中の周波数）と音名（例: `55.0 Hz / A1`）をリアルタイム表示。 |

> **ヒント**: 強くズームインした状態で60Hz以下のポイントをドラッグすると、周波数が0.2Hz刻みにスナップし、超低域の精密調整ができます。1Hzまでズーム可能です。

## 7. 技術仕様・システム要件

*   **動作環境**: Windows 10 / Windows 11 (64-bit 専用) ─ **Windows専用プラグインです**
*   **CPU要件**: **AVX2対応CPU必須**（Intel Haswell (2013) 以降 / AMD Excavator以降。SIMD最適化のため）
*   **動作保証ホスト (DAW)**: **Ableton Live 11以降のみ**（動作検証・確認済み）。その他のVST3対応DAWでも動作する可能性はありますが、動作保証・サポートの対象外です。
*   **プラグインフォーマット**: VST3 / Standalone
*   **フィルター設計**:
    *   カット: TPT (Topology-Preserving Transform) SVF によるButterworthカスケード＋リンギング低減ハイブリッドQ配置
    *   ベル: Orfanidis型（ナイキスト整合）biquad
*   **内部処理精度**: Double Precision (64-bit 浮動小数点)、AVX2 SIMDによるステレオ同時処理
*   **レイテンシー**: **0 サンプル**（遅延補正不要。トラッキング/ライブ使用可）
*   **アナライザー**: 800バンド SVFフィルターバンク（非FFT）、1Hz〜25kHz、マルチレート処理、8次アンチエイリアスフィルタ内蔵、0dBFSサイン基準キャリブレーション済み
*   **安全性設計**:
    *   音声信号パスおよびアナライザースレッド内での**動的メモリ確保（ヒープアロケーション）を排除**。
    *   パラメータ更新はロックフリー受け渡し（オーディオスレッドはロック待ちしません）。
    *   全パラメータのスムージングと構造変更時クロスフェードにより、**オートメーション時のクリック/ジッパーノイズなし**（実測検証済み）。
    *   NaN（非数）発生防止ガードを実装し、超高Q値設定時にも発振や爆音を防ぐ高耐性設計。
    *   無音が1.5秒続くと内部処理を自動サスペンドしてCPUを節約します。
