## 1. 製品概要

### コンセプト
**LowCut Police**は、楽曲の低域（サブベース、キックの不要な被り、マイクの吹かれノイズ等）を徹底的に管理・排除するために開発された高精度ローカットイコライザーです。オーディオの最もデリケートな帯域である低域をクリアにし、ヘッドルームを確保することを目的としています。

本プラグインは、多機能さを競う万能EQではなく、**「低域の不要な泥（Mud）を取り除き、ミックスの土台を完全にクリーンにする」という単一の目的に対して、音響的・技術的・操作的な最適解を徹底的に追求した、極めてシャープで実用的な「特化型プロフェッショナルツール」**です。

### フィルター形式の仕様（直線位相と最小位相のハイブリッド）
LowCut Policeは、各フィルターの性質に合わせて最適な位相特性を採用しています。
*   **ローカット（ハイパス）フィルター**: **ゼロフェイズ（リニアフェイズ / 直線位相）特性**。
*   **ベルEQ（1〜4バンド）**: **ミニマムフェイズ（最小位相 / Minimum-Phase）特性**。

### ゼロフェイズ（直線位相）テクノロジーについて（ローカット専用）
通常のイコライザー（最小位相）で急峻なローカットを適用すると、カットオフ周波数周辺で大幅な「位相ズレ（Phase Shift）」が発生し、低音の輪郭がぼやけたり、アタックのパンチが失われたりします。

LowCut Policeのローカット（ハイパス）は、**双方向 overlap-add (OLA) biquad フィルタシステム**を内蔵しています。入力信号を時間軸上で「前方」と「後方」の双方向から重ね合わせ処理することで、フィルタに起因する位相ズレを完全に相殺します。これにより、位相が完全にフラット（直線位相）な状態で不要な低域だけをスパッと削り落とすことが可能になります。
一方で、細かな音色調整を行うベルEQについては、音の立ち上がりと応答の自然さを考慮して、伝統的かつ音楽的なミニマムフェイズ（最小位相）特性を採用しています。

## 2. 各セクションとパラメータ解説

### ローカット（ハイパス）セクション
不要な低音をカットするためのメインフィルターです。
*   **Cutoff Frequency (Hz)**: カットする境界周波数を指定します（調整範囲: 20 Hz 〜 500 Hz、対数スケール）。
*   **Slope (dB/oct)**: フィルターの急峻さを設定します。12 / 24 / 36 / 48 / 60 / 72 / 84 / 96 dB/oct の8段階から選択できます（12dB/oct = 1次〜8次フィルタにマッピング）。
*   **Gain (dB)**: フィルターのカット量を微調整します（調整範囲: 0 dB 〜 -10 dB）。通常は最大の -10 dB にしてすっきりと削ります。
*   **Enable (ON/OFF)**: ローカットフィルター全体の有効/バイパスを切り替えます。

### ベルEQセクション（1〜4バンド）
特定の周波数を狙ってピンポイントでカットまたはブーストするためのパラメトリックイコライザーです。
*   **Freq (Hz)**: ターゲットとなる周波数を設定します（調整範囲: 20 Hz 〜 20,000 Hz）。
*   **Gain (dB)**: 増減量を設定します（調整範囲: -18 dB 〜 +18 dB）。不要な共振を吸い取るノッチカットや、低域を削った後の補正ブーストに使用します。
*   **Q**: フィルターの帯域幅を設定します（調整範囲: 0.1 〜 120.0）。Q値を大きくするほど、非常に鋭くピンポイントなカット（ノッチ）が可能になります。
*   **Enable (ON/OFF)**: 各バンドごとの有効/バイパスを切り替えます。

### グローバルコントロール / モニター系
*   **Bypass**: プラグイン全体の処理をバイパスします（バイパス時は赤く点灯）。
*   **Diff (Listen Diff)**: 後述の「差分聴取」モードを有効にします（有効時は青く点灯）。
*   **Color**: 10種類のカラーパレットを切り替えます。
*   **Analyze (表示モード切り替え)**: クリックするたびに描画ディスプレイが切り替わります：
    *   `Normal`: イコライザー応答カーブ ＋ リアルタイムFFTアナライザー表示。
    *   `Waveform`: ステレオ音声波形表示（左: Dry / 右: Wet）。
    *   `Phase`: 位相特性表示（左: Standard IIR位相 / 右: 理想的なZero-Phase特性 ＋ リアルタイムスペクトラム表示）。

## 3. 高度なモニタリング機能

### Listen Diff (差分聴取)
「Diff」ボタンをONにすると、遅延補正（Latency）を施した状態で **Dry音 - Wet音** を出力します。
これは、**「イコライザーによって削り取られた音成分そのもの」**を聴くための機能です。
*   **効果的な使い方**: ローカットを強くかけた際、削った音の中にキックの芯やベースの重要なメロディラインなど「音楽的に残すべき成分」が一緒に削られていないかを、このDiffモードで耳で確認できます。Diffから「不要なゴーゴーという風切音や不要低域ノイズ」だけが聴こえていれば、正しいイコライジングができている証拠です。

### Solo-Sweep (ソロスイープ)
EQドットを **`Shift` キーを押しながらクリックまたはドラッグ** している間、その操作ポイントを中心とした鋭いバンドパスフィルター（Solo Filter）が適用されます。
*   **効果的な使い方**: ドットをドラッグして左右に往復させる（スイープする）ことで、オケの中で不快に響いている「耳障りな共鳴周波数」や「濁った音」を簡単に探り当てることができます。ドラッグを離すと瞬時に元のイコライジング音に戻るため、素早く問題箇所を特定してピンポイントカット（ノッチ）に移れます。

## 4. 操作ショートカット一覧

マウス操作を極限までスピードアップさせる以下のショートカットに対応しています。

| 操作方法 | アクション |
| :--- | :--- |
| **`Ctrl` + ドラッグ** | **微調整モード**: 画面下のノブ、またはEQ画面上のドットをドラッグする際、ドラッグスピードが約1/10になり、**0.1 Hz単位** で超精密に周波数を狙い撃ちできます。 |
| **`Alt` + マウスホイール** | **ダイレクト可変**: EQ画面上のドット（または下部スライダー）にマウスカーソルを乗せてホイールを回すと、ベルEQの場合は **Q値** を、ローカットの場合は **Slope (dB/oct)** を直接素早く変更できます。 |
| **ダブルクリック** | **バイパス切り替え**: EQ画面上の操作ドットをダブルクリックすると、そのバンドの有効/バイパスが瞬時に切り替わります。薄く表示されているバイパス中のドットも直接ダブルクリックで復帰させられます。 |
| **`Shift` + クリック/ドラッグ** | **ソロスイープ**: 狙ったバンドの周波数周辺のみを一時的にソロで試聴します。 |
| **マウスホイール (空きスペース)** | **表示ゲイン調整 (Normal)**: アナライザー表示中にホイールを回すと、リアルタイムアナライザーの背景波形の位置を上下にスクロール調整（±30dB）できます。<br>**位相ズーム (Phase)**: 位相画面でホイールを回すと、縦軸の角度スケール（Zoom）を拡大縮小できます。 |

7.  **Ocean Abyss (オーシャンアビス)**: 深海をイメージしたクールなブルーグラデーション。
8.  **Forest Zenith (フォレストゼニス)**: 心地よい緑をベースにしたアースカラー。
9.  **Sunset Glow (サンセットグロー)**: 夕暮れのような美しいオレンジ〜赤のグラデーション。
10. **Midnight Gold (ミッドナイトゴールド)**: 高級感漂う漆黒と金色の組み合わせ。

## 6. 技術仕様・システム要件

*   **動作環境**: Windows 10 / Windows 11 (64-bit 専用) ─ **Windows専用プラグインです**
*   **動作確認済みホスト (DAW)**: **Ableton Live 11+ (動作検証・確認済み)** / Cubase 12+ / Reaper 6+
*   **プラグインフォーマット**: VST3
*   **内部処理精度**: Double Precision (64-bit 浮動小数点処理)
*   **レイテンシー**: 約 480ms (@ 96kHz) / Lookahead バッファ経由 (DAWによる自動レイテンシー補正(PDC)に対応)。
    *   **【警告】** 双方向処理（OLA方式）の特性上、避けて通れない大きな遅延（レイテンシー）が発生します。DAWの自動遅延補正（PDC）によって再生タイミングは完全に合いますが、レコーディング時やリアルタイム演奏中のインサート（挿入）には一切使用できません。 あくまでミックス・マスタリング専用のプラグインです。
*   **安全性設計**:
    *   音声信号パスおよびFFT解析バックグラウンドスレッド内での **動的メモリ確保（ヒープアロケーション）を完全排除（100%アロケーションフリー）**。
    *   DAW再生中の突然のメモリ不足によるフリーズや、マルチスレッドのロック競合によるプチノイズ（グリッチ）が発生しません。
    *   ゼロ除算・NaN（非数）発生防止回路を実装し、超高Q値設定時や過度なパラメータ操作時にも発振や爆音の発生を防ぐ高耐性設計。
